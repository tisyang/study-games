日期：2026-11-09。基线`76493ce`。用户确认先做第一阶段，由Codex直接实现；本批不自动提交、推送或发布。初版和12字扩充记录保留在[12号文档](12-preschool-prototypes.md)。

## 交付目标

- 内容先扩到30个汉字、18个完整双字词，为后续100字库建立可复用的组织方式。
- 把“优先新字”升级为新内容与跨轮复习混合，区分接触、独立辨认与场景运用。
- 数学补齐0—5数与量、排列变化后的数量保持、多一少一、零、分合；接着数增加隐藏结果的练习方式。
- 首页仍从“小小乐园”进入。乐园内三个入口：数字小乐园、汉字小世界、词语小剧场；每轮三个任务，无倒计时、排名或积分。

## 学习流程与复习

新内容：点规范大字/完整词卡认识含义 → 换场景完成字词选择。不同类型使用实物、动作、相对大小和位置等画面，运用题干避免直接含目标字或完整目标词。

复习交替采用：

1. **听音找字词**：播放完整名称，选择同色字词卡；不同时显示提示图片。
2. **看字词选画面**：显示字词，选择三幅不同画面；默认语音只说明任务，不读出答案。需要时可以回看认识场景。

每轮通常安排至多两个新内容，加一个复习；尚无可复习内容时允许三个新内容。不足三个新内容时补入复习。复习优先到期和较久未出现的项目，不把随机重复当作唯一策略。

### 本地记录

使用`kids_preschool_literacy_v1`保存完成轮数及字词记录，以`c:日`、`w:水果`等键区分。记录包括接触标记、初次接触轮数、独立辨认次数、独立运用次数、上次完成轮数及下次复习轮数。

- 点认识卡只记录接触，不增加独立能力次数。
- 新内容当场答对、同轮退出重进、答错后再答对、借助回看后答对，都不增加独立辨认/运用次数。
- 隔轮、无提示与错误重试时，才增加对应方向的独立次数。一次答对不标注“掌握”。
- 默认隔1轮再遇见；独立完成后把优先复习时间延后至2—3轮。到期项目优先，内容不足时允许提前复习。这里按完成轮数安排，不冒充按日历天数的间隔复习。
- 兼容旧`kids_preschool_letters_seen`，只迁移为“接触过”；字符答对仍维护旧标记。新记录为无效JSON时可以重新建立，星星存储不改。记录只在当前浏览器保存。

## 数字玩法

| 入口 | 三个任务/交互 |
| --- | --- |
| 数字找朋友 | 实物数量选数字；看数字实际装苹果再送出；换排列后再选总数。前两类随重玩覆盖0—5，排列变化任务覆盖1—5。 |
| 来一位，走一位 | 从原数量增加一位、减少一位、全部回家。操作只执行一次，结果由孩子选择；重玩覆盖0—4加一和1—5减一。 |
| 苹果分一分 | 把固定总数分到两个盘子，可放入和拿回；每轮探索三个不同的左右分配。重玩依次用总数3、4、5，支持一边为0；两边加剩余始终等于总数。 |
| 小熊接客人 | 保留2＋1、3＋2、苹果2＋2。“跟着学”显示接着报数；“自己试试”不播放或显示每次增加后的答案，保留从头数帮助。 |

数字不在操作前自动揭晓结果。装数量需要实际操作，数量不匹配不会通过；同一分法重复提交会要求换一种。完成后才展示数与量或算式对应。
