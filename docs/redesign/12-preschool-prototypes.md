# 小小乐园：数字与汉字样板

日期：2026-11-09。用户确认两个样板，并指定由 Codex 直接实现。本轮不调用 agy，不自动提交或发布。

## 目标与范围

面向4—5岁孩子，先建立“实物数量—数字”和“情境含义—汉字”的联系，再让孩子用同样的方法解决一个新任务。首页保留三个学科入口，另增“小小乐园”。两种游戏各一轮三个任务，无计时、连击、积分或排名。

### 小熊接客人

1. **看实物：2＋1。** 原有两位乘客完整可见，点一位新乘客上车，语音数“三”；随后在三个大数字中选择总数。
2. **记住原数：3＋2。** 原乘客暂时收起，保留“原来有3位”。点一位新乘客报“四”，再点一位报“五”。每次新增与接着报数一一对应，不把“三”算作新增的第一次。
3. **换情境：2＋2。** 改为野餐篮里的苹果，从已有的二接着数三、四，再选数字。

“从头数”始终可用：展开原有物品，逐个点击计数，每个只数一次。点数顺序不限；新增物品也能任意先选，不强迫左右顺序。错误后保留现场，支持继续尝试；全部新增后才出现数字选项，正确后显示完整算式并主动进入下一站。

本样板总数不超过5，没有加入10以内关卡或自适应难度。未来扩展前，先观察孩子是否能把“新增次数”与第二个数对应起来。

### 汉字小世界

首轮依次认识“日、月、水”；重玩从“日、月、水、山”中选三个。

- **认识与操作：** 语音说明字义，点规范大字，让太阳、月亮、流水或山的主体显现，再朗读简短名称。
- **迁移运用：** 换一幅场景，如河水变为浇花用水、月亮变为小熊睡觉时窗外的月亮，在三个同色字牌中选字。
- **按需回看：** 可以“再看一次”回到认识场景，继续尝试；答对后由孩子手动推进。

图片为代码绘制的简洁 SVG，图中不嵌字；字牌不绑定固定颜色或选项位置，避免靠颜色与位置记答案。没有加入描红、笔顺、拼音测验或大规模字库。

## 工程实现

- `index.html`：增加独立入口、视图和脚本/样式引用，原学科控制器不改。
- `js/preschool.js`：固定任务、有限状态与事件委托；利用既有语音引擎播放本地文件。每次切任务或退出停止当前语音，不安排延迟自动切题。
- `css/preschool.css`：独立作用域；大数字、规范大字、原生按钮；手机自然滚动；尊重减少动画偏好，操作后维护键盘焦点。
- `assets/audio/preschool/`：28条固定中文任务、反馈、汉字名称与一到五的报数MP3，沿用项目已有Google Translate TTS来源。文本、路径、字节数、SHA256与时长见 [语音清单](preschool-audio-manifest.json)。运行时不请求在线TTS。
- 幼儿玩法不读写星星奖励，不混入原有五题/十题答题状态。

## 本机验收

使用静态服务器与Chromium，视口1280×800、768×1024、390×844。临时使用Noto Color Emoji补齐宿主字体，产品不新增字体依赖。

- 两种玩法均完成三个任务，验证重玩、返回乐园、返回首页、退出停止语音。
- 数学验证2＋1、3＋2、2＋2的实物数量、每次新增后的报数路径、逆序选择待上车乘客、重复点击不增加两次、从头数不重复、错误重试与正确算式。
- 汉字验证首轮三个字的认识、点字变化、不同场景中的三选一、选项颜色一致、图中无嵌字、回看和错误重试；确定性重玩覆盖“山”。
- 检查可见子元素边界，三种屏幕均无横向越界；验证键盘Enter进入及操作后的焦点推进。
- 28条语音逐条匹配程序文本，校验文件SHA256并在Chromium加载解码，清单记录实际时长。
- 原首页三个学科、八个旧模式入口、Enter/Space键盘操作回归通过；另检查从幼儿玩法返回后仍能进入原加法。
- `node --check js/preschool.js`、`git diff --check`通过。
