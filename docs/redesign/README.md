# 儿童视角改版：设计与执行总纲

日期：2026-11-09。设计与验收：Codex；实现：agy / Gemini 3.8 Flash（首页 High，加法样板 Medium，审查修正 Low）。

第一批已完成本地实现与浏览器验收，结果见 [验收记录](03-acceptance.md)。未提交、推送或发布。后续学科玩法仍属于候选方案。

## 背景与目标

面向小学二年级孩子。当前页面说明文字、标签与装饰层级过多，场景和操作被挤小；核心玩法仍以选择答案后观看动画为主。改版目标：孩子无需成人逐段讲解，就能知道去哪玩、当前做什么、操作后发生什么。

暂按平板与电脑为主要设备，同时保证手机竖屏可用。这个设备假设尚未经过用户确认；窄屏允许自然纵向滚动，不能靠缩小文字硬塞一屏。

## 设计规则

- 每屏一个主要任务；场景、关键数字/诗句、操作按钮优先。
- 儿童界面删除教学术语、技术说明、题库数量和重复引导；保留必要的学科标识。
- 任务一句话。辅助解释按需出现，不把故事、提示、规则同时堆到屏上。
- 首要文字桌面建议 28～40px，主要算式 44～64px，答案 32～40px；手机可以适当调整，操作按钮至少 48px。
- 颜色用于区分可操作对象、任务重点和反馈；避免所有面板同时使用重边框、鲜艳徽章和跳动。
- 角色和场景承载趣味；优先复用素材，允许简单 CSS/内联 SVG 场景，不引入远程字体/图片、框架或生成素材依赖。
- 不用拖拽作为唯一交互。普通按钮同样可供触摸、鼠标、键盘操作。
- 音效辅助反馈；关闭音效后仍能通过文字和画面理解结果。
- 尊重 prefers-reduced-motion，重要变化即使关闭动画也能理解。

## 分期范围

## 工程边界

- 原生 HTML/CSS/JS，沿用现有普通 script 与 window 单例组织方式。
- 不改变题库、题目范围、静态 MP3 路径和已有星星存储 key。
- 不重构其他学科渲染器，不批量格式化，不升级依赖。
- 不提交、推送或部署；只修改当前工作区，交由 Codex 审核。
- 不读取或写入 __session.md；不接触凭据及运行环境配置。
- 按 01、02 顺序实施，每批完成后停下，报告涉及文件、检查方法和未验证项。

## 验收方式

本地浏览器检查与必要的逻辑检查；此项目不涉及交叉构建。孩子能否真正独立理解，需要后续实际试用，不能用自动化检查代替。

目标视口：1280×800、768×1024、390×844。核对文字大小、按钮可达性、横向溢出、焦点、声音关闭状态；手机允许纵向滚动。

检查入口→出题→错误→帮助→正确→下一题→结算→重玩→返回完整流程。除法、古诗、成语、英语各检查一道，确保共用布局未破坏。
