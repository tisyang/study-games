## 本批交付

1. 减法拆箱、乘法摆排、除法平均分的主动思考工具。
2. 32 个成语改成故事理解选择，答后揭晓成语。
3. 32 组古诗题采用无字、儿童绘本式淡彩国风配图；大画面和大诗句；诗意按需展开。
4. 12 组英语重写为角色短请求，图、语句、正确选项、反馈和本地 MP3 一致。

## 共同行为

- 七种探索入口（加减乘除、成语、古诗、英语）均为 5 题、无倒计时、答对后手动下一题。混合算术保留 10 题计时挑战与原演算。
- 每题只突出一个任务。主任务至少 24px；答案数值至少 32px；必要中文选项至少 24px；按钮至少 48px。窄屏自然滚动，不缩小字强塞首屏。
- 思考工具可选，直接作答也能完成。工具不重复执行；已完成工具隐藏；答对锁定，下一题只推进一次。
- 提示在场景内出现，不用长文字弹窗。错误不自动跳题。
- 现有星星 key、逐题与结算奖励沿用。结算描述“完成题数”，不声称首次正确率。
- 返回/重玩要清理场景定时器与语音；旧音频结束不能触发隐藏题目。尊重减少动画偏好，键盘可操作。
- 不新增框架、运行依赖、登录、商店、排行榜或通用配置系统。不要重排整份 CSS 或清理旧死代码。
- 本批只本地实现和验收，不自动提交、推送或发布。未授权读取/写入 __session.md。

## 执行分工与顺序

- Codex：本组设计文档、英语具体文本与古诗配图规范、图片生成与审查、音频资源同步、浏览器验收。
- agy：按 06 → 07 → 08 顺序实现。每次只执行指定任务并停止，必要修正另行指派。不调用其他 agent。
- 生成图片保存在 `assets/images/poems/v2/`，不破坏旧素材；每个题目 id 对应 `${id}.webp`。原始生成 PNG 保留在生成目录，站点使用压缩 WebP 降低加载成本。新资源缺失时显示简短可读替代状态，不能回退到有题字的旧图泄露答案。
- 32 个题目其实来自 16 首诗，每首两个片段；用户界面与新文档应准确称“16 首诗、32 组诗句”，不能继续扩大成 32 首不同古诗。
