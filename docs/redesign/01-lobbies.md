# 任务 01：首页与学科大厅

## 问题

首页每卡有徽章、图标、标题、介绍、四个标签和按钮。学科大厅又用长关卡名、介绍、标签重复解释。孩子需要先读产品说明再找入口。

## 目标布局

- 首页标题“今天想玩什么？”；品牌“乐学萌岛”保留在导航，无重复大品牌口号。
- 三个大场景按钮：松鼠与苹果 / 故事绘本 / 雨中的兔子。用简单 CSS/内联 SVG 或已有 emoji 配景营造明确场景，不能只是缩小的单个图标。
- 每入口只保留一处大名称和一处短学科标识：
  - “动物小帮手”，标识“数学”；
  - “故事与古诗”，标识“语文”；
  - “动物求助啦”，标识“英语”。
- 整张入口可点，有真实 button 语义，键盘 Tab/Enter/Space 可用。保留原入口 id，避免无谓改绑定。
- 移除筹备中的思维岛占位。作者/GitHub 信息保留页脚，导航 GitHub 图标移至页脚，音效与音乐功能仍保留。
- 桌面可三列，平板按空间调整，手机单列；不让孩子面对密集小卡片。

## 学科大厅

保留两级导航和原 data-mode，改成大图形配大短名称，不显示 card-desc/card-tag 的教学说明：

| 模式 | 显示名 |
| --- | --- |
| add | 收苹果 |
| sub | 松鼠拆箱 |
| mul | 烤饼干 |
| div | 分水果 |
| mix | 算术挑战 |
| idiom | 成语故事 |
| poem | 画中找诗 |
| english_story | 帮帮小动物 |

学科大厅标题可以“数学岛 / 语文岛 / 英语岛”，下方不再重复长教学介绍。卡片仍使用原模式，不改变旧模式的出题与玩法。加法进入任务 02 的探索模式。

## 代码范围

主要 index.html、css/style.css，js/app.js 只做标题/短文案等必要变更。先完成本任务，等待审核，再做任务 02。布局样式放在对应区段，移除本次替换造成的无用样式，勿重排整份 CSS。

## 验收

- 首页只有三项可玩的主入口；每项最多大名称＋学科标识，没有长说明或小标签串。
- 首页进入各学科、返回、八种关卡入口均工作。
- 390px 无横向滚动；三项均可通过自然纵向滚动到达；1280px 标题和入口清楚宽松。
- 卡片具有可见 focus-visible，键盘可操作，无按钮嵌套。
- 其他答题页未改变玩法，声音与星星显示功能正常。
